JAK UŻYWAĆ:
-----------
1. Zainstaluj zależności: pip install -r requirements.txt
2. Uruchom serwer - indeksy zostaną utworzone automatycznie
3. Otwórz stronę genealogii - automatycznie wykryje tryb ładowania
4. Dla dużych zbiorów zobaczysz pasek postępu
5. Admin może wyczyścić cache: POST /api/admin/cache/clear

TESTOWANIE:
-----------
- Małe zbiory (<1000 osób): tradycyjne ładowanie
- Duże zbiory (>1000 osób): paginowane ładowanie
- Sprawdź cache: zapytania powinny być szybsze przy drugim otwarciu
- Zmień dane przez admin panel: cache zostanie wyczyszczony automatycznie

KONFIGURACJA CACHE:
------------------
app.config['CACHE_TYPE'] = 'simple'              # In-memory cache
app.config['CACHE_DEFAULT_TIMEOUT'] = 3600      # 1 godzina TTL

Aby zmienić na Redis (dla production):
app.config['CACHE_TYPE'] = 'redis'
app.config['CACHE_REDIS_URL'] = 'redis://localhost:6379/0'
